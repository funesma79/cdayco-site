# Carolina Abril

Sitio estatico listo para desplegarse en Vercel sin proceso de build.

## Publicacion en Vercel

1. Importa este repositorio en Vercel.
2. Framework Preset: `Other`.
3. Build Command: vacio.
4. Output Directory: vacio.
5. Deploy.

Vercel detectara `index.html` en la raiz y servira el sitio como salida estatica.

## Archivos de despliegue

- `vercel.json`: headers y configuracion estatica.
- `robots.txt` y `sitemap.xml`: indexacion basica.
- `og-image.svg`: imagen social usada por Open Graph y Twitter.
